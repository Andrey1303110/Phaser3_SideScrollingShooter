# Actor artwork 1.8.0

The aircraft were generated with the built-in ImageGen tool using the previous aircraft atlases as references. The original dragon design was generated from text. Its airborne pose was redrawn using that same character sheet as the reference. These are editable high-resolution source masters, not runtime assets. `*-layout.json` preserves the original logical atlas layout. Run `./art/source/1.8.0/pack.ps1` from the repository root to repack the aircraft at 2× density. The game build copies the finished dragon atlas from `src/assets/sprites/`.

Runtime assets: `dragon.png`, `jet.png`, `strategic_jet.png`, `helicopter.png`, each with its JSON atlas, under `src/assets/sprites/`. World-space size is compensated in `actorArt.js`, `MovableObject.js`, and `GameScene.js`; menu heroes size themselves from actual frame width. Rotor positions are logical coordinates. Source masters are excluded from the Webpack asset copy because they live outside `src/assets`.

The dragon flies at 8 FPS. The third frame triggers the wing sound and the sixth starts the return motion. All ages share the same 306 × 238 frame and lip position (261, 122).

`gameplay-preview.jpg` is a development gallery rendered in the actual game scene, with the enemies placed in rows for inspection, not a normal encounter.

## Generation prompts

### Dragon

The master contains five compact wingless bodies and one detached wing. The flight artwork uses uniform body proportions, a 45° hip-to-shoulder line, a forward-facing muzzle and trailing hind legs. Both wings pivot at the shoulders and the tail follows the beat. Rows 0–4 contain the six flight frames for the fledgling through adult. Row 5 adds elder pigmentation to the adult pose. The game selects a row when all four upgrade levels reach a multiple of ten. After level 40, each decade strengthens the gold crest, horn rings and deep jade scales.

Edit the flight frames in `src/assets/sprites/dragon.png`. Their names and rectangles are in `src/assets/sprites/dragon.json`. Run `npm.cmd run build` to include the updated atlas in `dist/`.

Five WINGLESS body drawings of the same endearing little flying dragon growing older. Sixth piece is its one detached bat wing. A compact chunky quadruped, not a long Asian dragon or a lizard. Short plump pear-shaped torso, round chest, a short elegant S-curled tail that HOOKS UP behind the rump instead of extending sideways, visible tucked paws, short upright neck, big round expressive head looking RIGHT, tiny slightly parted mouth (no flames), golden eyes, warm cream muzzle and belly, sea-green hide. All five bodies in closely matching flight pose and scale, roughly 1.45 times as wide as tall, with the head level with the shoulders or slightly higher. Clean bold handpainted cel-shaded arcade illustration, dark teal tapered contours; details legible in a thumbnail. ROW ONE LEFT is a gentle fledgling: big bright eye, rounded muzzle, two tiny yellow horn buds, smooth simple jade skin. ROW ONE RIGHT is its juvenile stage: small backwards horns, few nape scales, curious face. ROW TWO LEFT: adolescent with slightly stronger chest, small orange crest, somewhat longer horns. ROW TWO RIGHT: young adult with a bolder copper crest, longer swept horns, still kind eyes. ROW THREE LEFT: confident mature adult with strong shoulders, amber cheek scales and handsome swept horns. Keep compact proportions and curled tail in all five bodies, exactly four legs, wings omitted for separate rigging. ROW THREE RIGHT: a SINGLE detached full dragon wing shaped like a scalloped leaf or bat sail, root is in lower RIGHT corner, wrist high near center-right, long fingers stretch LEFT, warm apricot/gold membranes, jade green leading bone, crisp graphic membranes with three fingers. Featherless. Entire parts have transparent margins and never touch. No lettering, labels, grid, shadows or scenery. Each figure should fill its equal square-ish cell.
