# Actor artwork 1.8.0

Generated with the built-in image_gen tool using the previous game atlases as references. These are editable high-resolution source masters, not runtime assets. `*-layout.json` preserves the original logical atlas layout. Run `./art/source/1.8.0/pack.ps1` from the repository root to repack the sources into `src/assets/sprites/` at 2× density; then run `npm.cmd run build`.

Runtime assets: `dragon.png`, `jet.png`, `strategic_jet.png`, `helicopter.png`, each with its JSON atlas, under `src/assets/sprites/`. World-space size is compensated in `actorArt.js`, `MovableObject.js`, and `GameScene.js`; menu heroes size themselves from actual frame width. Rotor positions are logical coordinates. Source masters are excluded from the Webpack asset copy because they live outside `src/assets`.

The dragon retains six frames at 8 FPS, frame 3 triggers the existing wing sound, frame 6 starts the return motion. Mouth registration remains approximately (140, 76) in the original 153×119 logical frame. The character follows the campaign introduction: a biological creature, not originally intended for war, tamed to defend Ukrainian skies. No armor or new lore was added.

`gameplay-preview.jpg` is a development gallery rendered in the actual game scene, with the enemies placed in rows for inspection, not a normal encounter.
